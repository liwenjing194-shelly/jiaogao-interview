## 网页试用

1. 双击本目录的 **`run_web.cmd`**，程序会打开浏览器。
2. 默认地址为 **http://127.0.0.1:8765**。如果服务已经启动，可直接打开该地址。
3. 选择“文字文案”或“海报图片”，输入材料；也可点击“风险文案”“商品介绍”“海报”填入自制样例。
4. 如有活动细则、数据来源等材料，在“补充判断依据”中填写。知道截图有缺失时勾选对应选项。
5. 点击“开始检查”，页面显示等待时间，通常约15—40秒。结果直接显示在右侧或手机布局下方。
6. 查看结论、风险原文、修改建议和人工复核要求；优先点击“保存 PDF 报告”，也可以保存 Markdown 备份或开发调试 JSON。
7. 修改材料后会提示旧结果已经过期；点击“重新检查”生成新结果。

检查按钮现在固定在浏览器底部，长页面、展开补充资料或缩放显示时仍能看到。新版结果区先显示管理层结论，规则依据默认折叠。更新页面前先复制尚未提交的文案，再按 Ctrl+F5 刷新；无需重启后端服务。

海报上传：切换到“海报图片”，点击“上传海报”打开文件夹，选择一张不超过10 MB的JPG或PNG。也可以把图片拖进上传区域，或复制截图后在页面按 Ctrl+V 粘贴。看到预览和图片尺寸后，点击底部“开始检查”。通过“更换图片”重新选择；“移除图片”会清空原图。损坏文件会提示重新导出，不会覆盖已经选好的图片。

线上底部会显示本演示环境的剩余检查次数，它是服务端体验额度，不等同于百炼账户免费余额。本版尚未自动监控账户额度；调用返回的 Token 用量不能直接推算免费余额。需要确认百炼余额时，请登录百炼控制台查看 `qwen-vl-max` 的剩余免费额度与过期时间，并按账户设置决定是否开启“免费额度用完即停”。[官方额度说明](https://help.aliyun.com/zh/model-studio/model-usage-statistics)

“检查记录”显示最近30份本机结果，打开记录不会再次调用模型。“规则说明”展示题目十条原文。网页下载只包含经过校验的最终结果，不包含未经保护处理的模型原始建议。

第一次启动时如果没有模型密钥，终端会提示隐藏输入，粘贴后回车即可；密钥不显示在网页中。运行窗口需要保留，关闭窗口或按Ctrl+C会停止服务。如果由助手在后台启动，可双击 **`stop_web.cmd`** 停止本项目服务。

本版使用Python自带HTTP功能，只监听本机回环地址；公网部署需要另行准备适合生产的服务、HTTPS和访问控制。Python官方也说明此HTTP模块不推荐用于生产环境。[官方说明](https://docs.python.org/3/library/http.server.html)


检查自己输入的文案：

```powershell
python -X utf8 check.py --text '全网第一，100%有效！今天下单立减50元！'
```

检查图片，将路径换成你的 JPG/PNG 文件：


## 规则与结果

结果区区分“初筛通过，未发现明确规则风险”“信息待补充，暂不能完成初筛”“发现规则风险，建议修改后复查”。未发现风险时仍可展示独立的“可选优化建议”，不计入待处理问题数，也不影响初筛结论。真实规则问题不会因为等级低而自动放行。历史报告保留当时结论；要使用更新后的判断提示词，需重新提交检查。

`rules.json` 从原始作业 Word 表格提取 A-01 至 A-10，保留编号、标题、要求原文。每次请求均包含十条完整规则。

模型逐条返回“发现风险／未发现风险／无法判断／不适用”。程序验证编号唯一、十条齐全、必填字段类型正确，并从规则文件补入对应规则原文。每项问题都有原文、风险类型、规则、等级、建议及人工审核字段。

首轮真实测试发现模型会在建议中示例编造活动日期或新增“多数用户反馈有效”等无依据表述，已改为由程序按规则填入保守整改模板。本原型对所有风险与证据缺口要求人工确认。JSON中的 `raw_model_report` 仅供开发排错，可能包含未经修正的建议；展示与使用请看 `report` 或Markdown报告。首份 `20260906_120147_136156_文字真实自测` 记录是修复前结果，应以之后的“修复后文字自测”结果为准。

程序另外强制处理：可见文本命中A-06敏感词时要求人工审核；声明截图不全、模型报告阅读限制或未读出图片文字时，不能输出完整的未发现风险结论。文字风险引用必须实际存在于原文。

图片原文来自模型识别，目前未用独立OCR或坐标逐字核验，也无法保证检测所有裁剪。自动生成的建议可能仍有遗漏或误报，需要结合原材料复核。低、中、高、待确认属于本项目分级，不是题目给定的分级标准。

## 接口异常

- HTTP 401：核对密钥是否有效、密钥与接口地域是否匹配。
- HTTP 403：检查该账户的模型调用权限与服务状态。
- HTTP 404：检查控制台可用的模型ID及接口地址。
- HTTP 429：检查可用额度和请求频率。
- 网络错误：先检查网络可否访问官方接口；程序不会把失败标成通过。
- 输出校验失败：本次检查未完成，需检查提示词或模型输出稳定性，不可当作未发现风险。

本版不自动重复付费请求；用户重试时会发起新的调用。
